• Se introduce la función submitFormRecibeJson, que permite enviar los datos capturados en un formulario hacia una URL.

  • Si la forma no tiene archivos, se usa el formato application/x-www-form-urlencoded.

  • Si la forma tiene archivos, se utiliza el formato mutipart/form-data, lo cual permite transmitir el contenido de archivos.

  • Para usarla, debes importar el archivo donde está definida esta función y luego invocarla pasándole la URL del servicio que precesa los datos, el formulario y el método de envío, que por omisión es POST.

  • A lo largo de esta lección y las siguientes, se profundiza en el uso y estructura de esta función.
